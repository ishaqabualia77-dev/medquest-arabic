
## Student timed exam simulation (MVP)

The student app includes a timed exam simulation for each independent exam track. Students can choose 10, 20, or 40 questions (capped by the number currently available), receive 72 seconds per question, navigate backward/forward, submit early, and review the score and explanations after submission. Exam answers contribute to the existing per-track browser-local progress. This is a practice simulation using the current sample question set; it is not an official exam blueprint, and cloud account synchronization is not yet enabled.
